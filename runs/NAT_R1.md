## Q2（逻辑推理）

【思考】
五人甲乙丙丁戊，名次 1–5 无并列。规则：第 1、2 名说真话，第 3、4、5 名说假话。

各人陈述：
- 甲：我不是最后一名（甲≠5）
- 乙：丙是第一名（丙=1）
- 丙：戊是第三名（戊=3）
- 丁：我不是第二名（丁≠2）
- 戊：甲的名次比乙靠前（甲<乙，指甲的排名数字更小）

关键突破口先看丁。丁说"丁≠2"。这句话的真假取决于丁的名次：
- 若丁在 1、3、4、5 名，则"丁≠2"为真；
- 只有丁=2 时该句才为假。
而规则要求：说真话者必须在 1、2 名，说假话者必须在 3、4、5 名。
  - 若丁是 3、4、5 名（应为假话），则要求"丁≠2"为假 → 丁=2，矛盾（丁在 3、4、5 却又=2，不可能）。
  - 若丁=2（应为真话），则"丁≠2"为假，矛盾。
  - 所以丁只能是第 1 名（真话，且丁≠2 成立）。
结论：丁 = 第 1 名。

再看乙。若乙=1，则乙说"丙=1"为真，与乙=1 冲突，故乙≠1。若乙=2（真话），则丙=1；但丁已=1，冲突。所以乙≠1、乙≠2，乙必在 3、4、5 名（说假话），于是"丙=1"为假 → 丙≠1。

现在剩下的真话者（第 2 名）只能在 甲、丙、戊 中。
考虑丙：若丙说假话（在 3、4、5），则"戊=3"为假 → 戊≠3。但丙≠1 已定，丙若在 3、4、5 则第 2 名只能是 甲或戊。
  - 若戊=2（真话），则"甲<乙"真。又丙假→戊≠3。此时丁=1、戊=2，剩下 3、4、5 给甲、乙、丙。甲∈{3,4,5} 说"甲≠5"：若甲=3 或4 则为真，但甲应为假话，矛盾；故甲只能=5（使"甲≠5"为假，符合假话）。于是乙、丙占 3、4，且甲<乙 即 5<乙，但乙∈{3,4}，不可能。矛盾。
  - 若甲=2（真话），则戊∈{3,4,5} 说假话，戊≠3（丙假推得），故戊∈{4,5}；戊说"甲<乙"为假 → 甲≥乙 → 2≥乙，但乙在 3、4、5，乙≥3，矛盾。
所以丙不能是假话者，丙必为真话者，即丙=第 2 名（因丙≠1）。

丙=2 为真话 → "戊=3"为真 → 戊=第 3 名（假话者，合理）。
剩下 4、5 名给甲、乙。戊=3 说假话，其"甲<乙"为假 → 甲≥乙。乙、甲分占 4、5：若乙=5、甲=4，则 4≥5 不成立；若乙=4、甲=5，则 5≥4 成立。故乙=4、甲=5。
验证甲=5（假话）："甲≠5"为假，符合。乙=4（假话）："丙=1"为假（丙=2），符合。全部自洽。

【答案】
五人名次为：丁第 1，丙第 2，戊第 3，乙第 4，甲第 5。
缩小范围的关键步骤：① 由丁的陈述"我不是第二"推出丁只能是第 1 名（唯一让该句既真又符合真话者身份的位置）；② 排除乙为 1、2 名，得乙必为假话者，从而丙≠1；③ 检验丙为真话者（否则会与戊、甲的真假约束矛盾），定丙=2、戊=3；④ 由戊（假话）"甲<乙"为假推得甲≥乙，锁定甲=5、乙=4。

## Q3（汉语语义）

【思考】
这是汉语"差点（没）X"的经典语义问题。规律（吕叔湘等）：要看 X 是"企望/积极"事件还是"不企望/消极"事件。
- "差点 X"：无论 X 积极消极，都表示 X 没发生（只差一点）。
- "差点没 X"：
  - 若 X 是积极/企望事件（如考上、进球），则"没"起反转作用，表示 X 发生了（侥幸做成）。
  - 若 X 是消极/不企望事件（如摔倒、死），则"没"不反转，仍表示 X 没发生。

逐组判断：
(1) 摔倒——消极事件。
  - 他差点摔倒 → 没摔倒（险些跌倒，没跌）。
  - 他差点没摔倒 → 没摔倒（同样没跌）。
  两句相同。
(2) 考上大学——积极事件。
  - 他差点考上大学 → 没考上（落榜，差一点）。
  - 他差点没考上大学 → 考上了（压线录取，侥幸）。
  两句不同。
(3) 死——消极事件。
  - 他差点儿死了 → 没死。
  - 他差点儿没死 → 没死。
  两句相同。
(4) 进（球进了，对说话方为积极事件）——积极事件。
  - 球差点进了 → 没进。
  - 球差点没进 → 进了（擦着门线进了）。
  两句不同。

【答案】
- (1) 相同：两句都表示"他没摔倒"（险些跌倒但没跌）。
- (2) 不同：前者"他差点考上大学"=没考上（落榜）；后者"他差点没考上大学"=考上了（压线录取）。
- (3) 相同：两句都表示"他没死"。
- (4) 不同：前者"球差点进了"=没进；后者"球差点没进"=进了（擦边进球）。

规律总结：当 X 为不企望/消极事件时，"差点（没）X"都表示"X 未发生"；当 X 为企望/积极事件时，"差点 X"=X 未发生，"差点没 X"=X 发生（"没"只在积极事件上起反转作用，表示侥幸达成）。

## Q4（汉语断句）

【思考】
"下雨天留客天留我不留"是著名的无标点句，断句不同意思完全相反。我从"谁留、谁不留"两个主体（天/主人与客）来构造几种读法。

【答案】
至少三种合理断句：

1. 下雨天留客，天留我不留。
   停顿：下雨天留客 ‖ 天留 ‖ 我不留。
   意思：下雨本是留客的天（天意留客），但"天留"而"我不留"——主人说自己虽知天意留客，却不肯留，是主人拒客。

2. 下雨天，留客天，留我不？留！
   停顿：下雨天 ‖ 留客天 ‖ 留我不 ‖ 留！
   意思：客人争辩：下雨的日子、正是留客的日子；（你）留我不留？（当然）留！是客人强求被留，反问后自答"留"。

3. 下雨天留客天，留我不留？
   停顿：下雨天留客天 ‖ 留我不留？
   意思：把"下雨天"说成"留客天"，然后问主人"你到底留我不留？"——客人以"天意留客"为由，质问主人去留。

（另可补充）4. 下雨，天留客；天留，我不留。
   意思：下雨了，天要留客；天留客，但我（主人）不留。同样主人拒客。

## Q5（英语句法歧义）

【思考】
"The chicken is ready to eat." 的歧义在于不定式 to eat 的逻辑主语（谁吃）不定。形容词 ready 后接不定式，chicken 与 eat 的关系有两种可能：
- chicken 是 eat 的"受事/宾语"（被吃）：鸡（这道菜）已经做好了，可以（被人）吃了。
- chicken 是 eat 的"施事/主语"（去吃）：鸡（活禽）自己饿了，准备好去吃东西了。

【答案】
(a) 两种理解：
  1. 这只鸡（做好的菜）已经可以吃了。——chicken 是被吃的对象。
  2. 这只鸡（活禽）已经准备好去吃东西了（它饿了）。——chicken 是吃的主语。

(b) 句法机制：歧义来自不定式 to eat 的隐含逻辑主语（PRO / understood subject）的绑定方式不同。"ready to eat"中，ready 的补语是不定式短语；chicken 既可以作为该不定式的宾语（承受 eat 的动作，隐含外部施事"人"），也可以作为该不定式的主语（通过主语控制/subject control 由 chicken 充当 eat 的施事）。即 chicken 在不定式里究竟是"主语"还是"宾语"未定，造成歧义。

(c) 消歧改写：
  1. 表"可被吃"：The chicken is ready to be eaten.  /  The chicken is ready for us to eat.
  2. 表"鸡自己要吃"：The chicken is ready to eat its food.  /  The chicken is hungry and ready to eat.

## Q6（英语韵律）

【思考】
判断 iambic pentameter 看两点：总音节数是否为 10，音步是否为 5 个"抑—扬"（unstressed–stressed，即 x /）排列。
逐词划分："Shall I comPARE thee TO a SUM mer's DAY"
- Shall（轻）I（重） → x /
- com（轻）PARE（重） → x /
- thee（轻）TO（重） → x /
- a（轻）SUM（重） → x /
- mer's（轻）DAY（重） → x /
共 10 个音节、5 个音步，每步都是抑扬格。

【答案】
音节数：10 个（Shall-I-com-pare-thee-to-a-sum-mer's-day）。
音步与重音（x=轻，/=重）：
Shall I / comPARE / thee TO / a SUM / mer's DAY
x / x / x / x / x /
结论：是标准的抑扬格五音步（iambic pentameter）。此句即莎士比亚《 sonnet 18》首行。

## Q7（跨文化语用）

【思考】
这是英式间接语用（understatement / polite disagreement）的典型例子。"with all due respect"是约定俗成的"前置礼貌套语"，几乎总是用于即将提出异议或批评之前，字面客气、实则警示"我要唱反调了"。"I would suggest…"用 would 弱化语气，但内容是指令性的，本质不是随便建议而是要求重做。"looking at this again"暗示当前版本有问题、需要返工。所以整体不是温和建议，而是礼貌包装下的否定/施压。

【答案】
(a) 真实态度：并非只是温和地建议"再看一遍"，而是礼貌地表达了对当前成果的异议/不满，要求返工。表面客气、实则施压。

(b) 支持该判断的语言信号：
  - "with all due respect"：英式套语，专用于提出异议前，表面致意、实际预告"我要反对"，常带反讽意味；
  - "I would suggest"：情态动词 would 软化和缓，但句义是指令/纠正，不是随意提议；
  - "looking at this again"：暗示现有版本不够好、需要重看，隐含否定评价；
  - 整体间接、克制，正是英式"话越轻、意越重"的批评风格。

(c) 作为中方团队负责人的回复要点：
  - 不要只接表面意思，要识别这是"不同意的批评"，认真对待；
  - 主动追问具体问题："能否指出希望重做的部分/具体顾虑？"——因为英方含蓄，不问会抓不到真实痛点；
  - 正面回应、不 defensive，给出明确下一步：如"我们重做 X/Y，某日前发修订版"；
  - 给双方留面子，语气尊重但直接。
  理由：英式间接批评若只回应字面"好的没问题"而回避实质，真正问题会积压；用具体、直接的追问把隐含异议摊开，才能有效解决。

## Q8（代码）

【思考】
回文判断：先"清洗"字符串——去掉空格和标点、统一大小写，再比较清洗后字符串与其反转是否相等。
难点在 Unicode：
- 中文等 CJK 字符是字母类（Unicode 类别 Lo），`str.isalnum()` 对它们返回 True，对空格和标点返回 False，所以用它可一次性过滤掉空格和标点，且保留中文字。
- 大小写：用 `str.casefold()` 比 `lower()` 更彻底（能处理更多 Unicode 大小写，如德语 ß），中文不受其影响。
清洗后 `cleaned == cleaned[::-1]` 即可。

【答案】
```python
def is_palindrome(s: str) -> bool:
    # 只保留"字母/数字"（isalnum 对中文等 CJK 也返回 True，
    # 而空格、标点返回 False，从而被自动剔除），并用 casefold 统一大小写
    cleaned = [ch.casefold() for ch in s if ch.isalnum()]
    cleaned = ''.join(cleaned)
    return cleaned == cleaned[::-1]
```
说明：用 `str.isalnum()` 处理 Unicode 标点与空格——它对英文字母、数字、以及中文等文字（Unicode 字母）都返回 True，对空格和标点符号返回 False，因此空格和标点被自然过滤，中文被保留；大小写差异用 `str.casefold()`（比 `lower()` 更通用的 Unicode 大小写归一化）消除，中文不受影响。例如 `is_palindrome("上海自来水来自海上")` 返回 `True`，`is_palindrome("A man, a plan, a canal: Panama")` 也返回 `True`。

## Q10（英文语境计算）

【思考】
先算总需求量，再换算成汤匙，最后用 1/4 杯（=4 汤匙）尽量取整、余数用汤匙补。
- 原需 3/4 杯，做 2.5 倍：3/4 × 2.5 = 0.75 × 2.5 = 1.875 杯。
- 1 杯 = 16 汤匙，所以 1.875 杯 = 1.875 × 16 = 30 汤匙。
- 1/4 杯量勺 = 4 汤匙。用它能舀的次数取整数：30 ÷ 4 = 7 余 2，即 7 次 1/4 杯 = 28 汤匙，余 2 汤匙用 1 汤匙量勺舀 2 匙。
- 校验：7×(1/4)=1.75 杯；2 汤匙 = 2/16 = 1/8 = 0.125 杯；合计 1.75+0.125 = 1.875 杯，正确。

【答案】
需用 1/4 杯量勺舀 7 次，再用 1 汤匙量勺舀 2 匙。
换算过程：
- 需求 = 3/4 杯 × 2.5 = 1.875 杯；
- 1 杯 = 16 汤匙 ⇒ 1.875 杯 = 1.875 × 16 = 30 汤匙；
- 1/4 杯 = 4 汤匙 ⇒ 30 ÷ 4 = 7 余 2；
- 故 7 次 1/4 杯（=28 汤匙 = 1.75 杯）+ 2 汤匙（=0.125 杯），合计 1.875 杯，正好。
