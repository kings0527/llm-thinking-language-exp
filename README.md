# LLM 思考语言实验：思考时用中文还是英文，会影响结果吗？

一项针对"LLM 推理语言是否影响输出质量与成本"的盲法对照实验。4 个实验条件 × 23 轮/条件，共 **70+ 份独立答卷**，覆盖中等难度题、高难度题、镜像长链压力测试三类任务，附统计功效分析与完整原始数据。

## 一句话结论

**思考语言对答案正确性没有可测量的影响（效应 < 4%，置信区间跨 0），但对推理成本有 21% 的真实影响** —— 中文思考因 tokenizer 编码效率低（1.16 vs 3.11 字符/token）比英文思考多耗约 21% token。

## 实验设计

| 条件 | 处理 |
|---|---|
| **EN** | 强制英文逐步推理，答案用中文 |
| **ZH** | 强制中文逐步推理，答案用中文 |
| **NAT** | 不指定思考语言（观察默认行为） |
| **ADAPT** | 先判断题型、每题自选思考语言 |

防污染措施：
- **盲法**：每份答卷由独立子代理完成，不知道实验假设与其他条件存在
- **操纵检验**：事后统计推理段的中英文字符占比，验证指令真实生效（EN 3.6%，ZH 73.5%，NAT 76.5%，ADAPT 28.2%）
- **顺序轮换**：正序/倒序/乱序三序循环，消除题目顺序效应
- **金标准代码验证**：逻辑题用位掩码搜索唯一解组合，组合计数题暴力枚举 5040 种排列，长链题逐步骤对照累积值

## 核心发现

1. **准确率**：EN vs ZH 总分差 +1.8%（12 分制），Welch t(44)=1.48，p=0.138，不显著；95% CI [−0.6%, +4.2%]。
2. **成本**：中文思考比英文多耗 21% token。四条件总输出接近（1.28–1.39 万 token），但分配相反——EN 想得少说得多，ADAPT 想得多说得少（答案短 44%）。
3. **元认知**：不指定时模型默认用中文思考（~70%）；允许自选时主动把 70–80% 思考切成英文；默认切换模式与刻意自适应高度一致。
4. **纵向复杂化无效**：50 步镜像长链（同一数字序列 × 中/英/数字三种表述）6 组全对；200 步 4 组、800 个步骤值 100% 精确。语言只是编码层，机械长链不产生语言效应。
5. **堆轮次 ROI 低**：功效分析显示检测下限按 √n 收缩——20 轮可检测 ≥4.3%，50 轮 ≥2.7%，检测 1% 需 364 轮/组。

## 评审要点（我们踩过的坑）

复现或设计类似实验时请注意：

- **盲评 LLM 会失效**：两名盲评子代理给出全部满分（零区分度）。必须先对客观题做机械核对来验证评分有效性。
- **自动评分器三类 bug**（均已人工终审纠正）：
  1. 用正则提取"结论"时抓到推理中间假设（如逻辑题答案里的"若 C 是骑士"）
  2. 答卷为解释错误而引用原错误句（"不能说 despite of"）导致反向误判
  3. markdown 粗体（`**meeting**`）干扰关键词匹配
- **小样本方向不可信**：n=3 时 ZH 在唯一区分题上略优（2/3 vs 1/3），扩到 n=23 后方向反转（EN 56.5% vs ZH 34.8%，仍不显著 p=0.24）。
- **天花板效应**：中等难度卷 12/12 全满分。测语言效应必须先把难度校准到能产生真实失误。

```
├── report.html              # 完整实验报告（图表/数据/建议）
├── README.md
├── questions.md             # 第一轮题库（中等难度 10 题）
├── rubric.md                # 第一轮评分细则
├── hard_questions.md        # 第二轮题库（高难度 6 题）
├── hard_rubric.md           # 第二轮评分细则
├── deep_cn_50/200.md        # 镜像长链题（中文数字表述）
├── deep_en_50/200.md        # 镜像长链题（英文数字表述）
├── deep_num_50.md           # 镜像长链题（阿拉伯数字表述）
├── deep_gold*.json          # 长链题金标准（逐步累积值）
├── runs/  runs2/  runs3/    # 全部原始答卷（70+ 份，未修改）
├── blind/                   # 匿名化答卷与映射表
├── by_question_*.md         # 按题聚合的答案视图
├── h5_c_extracts.txt        # H5 争议题的 (c) 段提取（供立场复核）
├── h5_judged.json           # H5 逐份人工判定记录
├── scores*.json             # 自动评分与人工修正记录
├── manipulation_check*.json # 操纵检验（思考语言占比）
├── token_stats.json         # token 统计
├── *_results.json           # 各轮结果汇总
│
│ ── 脚本（均可独立运行，路径自适应）──
├── gold_check.py / gold_check2.py / find_puzzle.py   # 金标准暴力验证
├── parser.py                                          # 答卷解析（行首标题匹配）
├── manip_check.py / analyze2.py                       # 操纵检验
├── anonymize.py                                       # 答卷匿名化
├── objective_check.py / score_auto.py                 # 机械评分
├── final_stats.py                                     # 最终统计（t 检验/Fisher/CI）
├── token_analysis.py                                  # token 成本分析（需 tiktoken）
├── gen_deep.py / gen_deep200.py                       # 长链题生成器（含金标准）
├── analyze_deep.py / analyze_deep200.py               # 长链逐步判分
└── power_analysis.py                                  # 统计功效分析
```

## 复现

```bash
# 金标准验证（无依赖）
python3 gold_check.py        # 第一轮客观题
python3 gold_check2.py       # 第二轮客观题（含逻辑题唯一解搜索）
python3 power_analysis.py    # 统计功效分析

# 长链题生成（无依赖）
python3 gen_deep200.py

# 最终统计
python3 final_stats.py       # Welch t / Fisher 精确检验 / 置信区间

# token 分析（需要 tiktoken）
pip install tiktoken
python3 token_analysis.py
```

所有脚本路径自适应（基于脚本所在目录），clone 后可直接运行。

## 引用方式

如需引用本实验结论，请注意其边界：结论适用于"现代强 LLM + 无外部工具 + 单次作答 + 任务处于模型能力范围内"的情形；不外推至固定思考预算、极难任务或多智能体场景。
